# Coding provenance

Every label in data/coded/ was produced by a Claude model instance run as a Claude Code subagent (model ids in briefs.jsonl; coders were claude-sonnet-5-5), one batch per instance, with no access to venue, year or any other batch. briefs.jsonl holds every coding brief dispatched, in time order and verbatim apart from local paths (BASE = this repository), including briefs whose output was later superseded. batch-brief-map.json maps each file in data/coded/ to the brief that produced its current content (template hash and brief number). Superseded labels are kept in data/coded-superseded/: the partial-read batches, first coded from partly displayed abstracts and re-coded from the full abstracts (docs/census-methods.md, section 10). Each brief instructed the coder to open only the codebook and its batch file (an instruction, not a sandbox); the data/batches/ files are those inputs.
