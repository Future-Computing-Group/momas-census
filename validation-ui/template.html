How to code a paper

Code from the title and abstract only, for the setting the paper's method or analysis assumes, not settings it mentions in passing (an example task, a motivation sentence).

Agent
Yes if the subject is one or more decision-makers that act over several steps in an environment: RL agents, LLM agents that call tools or act on the web or in software, robots, bidders, players. No if an agent only helps build a dataset or is a one-shot model call.
Interests
Whose interests the formal setting models. One. Several aligned (shared goals, e.g. a cooperative team). Several conflicting (distinct, possibly opposed goals: game opponents, bidders, negotiators, competing firms). Adversarial (an attacker or threat model against one protected party). Not fixed, when the abstract does not say.
Owners
How many independent parties own or control the decision-makers. One: a single developer, operator or trainer controls them all, including self-play, simulated opponents, and independently developed models run side by side in one evaluation. Several: decision-makers or data owners belong to different organizations or people, e.g. federated clients, human participants acting for themselves, an external attacker.
Boundary
Yes if decision-makers or data owners on different sides of an ownership line interact in the setting.
Default
A paper in which one developer trains or runs one model is the default ML setting: interests one, owners one, boundary no, whether or not it is an agent paper. Not fixed is for papers with no learner, decision-maker or analyst at all, such as a pure hypothesis test.
